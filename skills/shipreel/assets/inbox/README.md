Drop new memes, SFX, GIFs or music here, then run:

    python ../../scripts/assets.py scan                  # lists unindexed files
    python ../../scripts/assets.py sheet --dir inbox     # one image to look at many at once
    python ../../scripts/assets.py add inbox/x.png --type image --name what-it-shows --moods smug --themes success --text "caption on it" --move

Name files by what they show ("drake-no-yes", "dog-in-burning-room"), not where they came from.
